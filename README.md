# وسام سناك — تطبيق الطلب أونلاين

## الملفات
- `index.html` — الصفحة الرئيسية (المنيو + السلة + الطلب)
- `admin.html` — لوحة إدارة الطلبات (خاصة بصاحب المحل فقط)
- `style.css`, `app.js`, `admin.js`, `menu-data.js` — الكود
- `firebase-config.js` — إعدادات قاعدة البيانات (لازم تعبيها، شوف تحت)
- `manifest.json`, `service-worker.js`, `icons/` — إعدادات الـ PWA (تثبيت التطبيق على الهاتف)

## خطوات التشغيل

### 1) إعداد Firestore (لتفعيل لوحة الإدارة)
بدون هالخطوة، الموقع بيشتغل 100% (منيو + سلة + طلب واتساب) بس الطلبات ما بتنحفظ بلوحة الإدارة.

1. روح على https://console.firebase.google.com وأنشئ مشروع جديد (يفضل مشروع منفصل عن أكلاتنا).
2. من القائمة الجانبية: **Firestore Database** → Create database → اختر **production mode**.
3. من **Project settings → General → Your apps** أضف تطبيق ويب (</> ), وانسخ الـ `firebaseConfig`.
4. افتح ملف `firebase-config.js` واستبدل القيم `REPLACE_ME` بالقيم الحقيقية.
5. من تبويب **Rules** بالـ Firestore، حدّث الصلاحيات حتى يقدر الموقع يكتب طلبات ولوحة الإدارة تقرأهن (مثال أولي بسيط، ينصح بتحسينه لاحقاً بمصادقة حقيقية):

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /orders/{orderId} {
      allow create: if true;
      allow read, update: if true;
    }
  }
}
```

### 2) رمز دخول لوحة الإدارة
الرمز الافتراضي هو **1234** — **غيّره قبل ما تنشر الموقع**. التعليمات موجودة بأعلى ملف `admin.js`.

### 3) النشر
نفس طريقة أكلاتنا: ارفع كل الملفات (كمجلد) على Cloudflare Pages عبر GitHub (رفع يدوي، بدون git CLI)، أو أي استضافة static hosting ثانية.

### 4) الدفع عبر Whish Money
حالياً الدفع عبر Whish هو **تحويل يدوي مؤكَّد**: الزبون يشوف رقم Whish (03 644 720) والمبلغ المطلوب، يحوّل من تطبيقه، وبيقدر يكتب رقم مرجعي بالطلب لتسهيل التأكيد من طرفكم. فيه زر "افتح تطبيق Whish" (deep link تجريبي) بس مش مضمون يشتغل عالكل الأجهزة لأن Whish ما عندها توثيق رسمي لهيدا الرابط.

لو حبيت لاحقاً دمج **دفع حقيقي (charge مباشر)** بدون خروج من التطبيق، هيدا بيتطلب حساب تاجر (Merchant) رسمي مع Whish Pay — لازم تتواصل معهم مباشرة كصاحب العمل للحصول على API credentials، وبعدها فينا نربطها بالتطبيق.

### 5) تعديل المنيو
كل الأصناف والأسعار موجودة بملف `menu-data.js` — سهل تضيف/تحذف/تعدّل بدون لمس باقي الكود.
